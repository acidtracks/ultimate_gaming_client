L'axe

Pas le cloud. Ta machine.

Ultimate Gaming Client stream les jeux depuis ton PC — ta carte graphique, ta bibliothèque, ton réseau local — vers ta TV LG. C'est l'opposé exact d'un service cloud comme GeForce NOW : rien ne transite par les serveurs de quelqu'un d'autre, la seule distance c'est celle du salon.

Cet écart est la marque. Un service cloud vend un abonnement et une promesse ; nous, on vend la fidélité d'une liaison. Ce que l'utilisateur avancé regarde vraiment, c'est l'overlay de stats : latence estimée, cadence réelle, débit, perte de paquets. L'identité vit dans ce vocabulaire — celui d'un panneau de contrôle, pas d'une pub.

Le symbole doit dire deux choses d'un coup : on lit un jeu, et le lien est bon.

Trois qualités à porter, dans cet ordre :

  • Rapide — faible latence, réactivité. Des formes nettes, tranchantes, orientées vers l'avant.
  • Fidèle — chaque image arrive. Une palette de télémétrie : vert-signal quand ça tient, magenta quand ça lâche.
  • À toi — pas corporate, pas cloud. Noir OLED, typo d'équipement, ton direct.
02 / 07

Le symbole

La lecture, plus le signal.

Un triangle de lecture — universel, « joue » — suivi de trois barres montantes : la jauge du lien, la force du signal, la montée en débit. Ensemble : « ça joue, et ça passe bien ».

Le dégradé spectral (cyan → violet → magenta) n'apparaît que dans le symbole : il représente le spectre du signal vidéo à plein débit. Partout ailleurs, l'interface reste sobre.

Sous 32 px, les barres fusionnent : le symbole se réduit alors au triangle plein seul. Dégradation prévue, pas subie.

Chakra Petch, capitales, chanfreiné.

La couleur

Une palette d'overlay de stats.

Le fond, c'est le noir d'une dalle OLED éteinte — le salon dans le noir, le pixel au repos. Deux accents seulement, et ils ont un rôle, comme dans un OSD : le vert-signal dit « ça tient », le magenta dit « ça lâche ».

--ink#05060A Fond. Noir OLED. Le pixel éteint.
--panel#0E1119 Surface. Panneaux, cartes, l'OSD.
--line#232C3D Filets. Grille, séparateurs. Gris biaisé cyan.
--muted#8C98A2 Texte secondaire. Légendes, unités.
--signal#4DF3D0 Lié / bon. Accent principal. Faible latence, verrouillage.
--drop#FF3D8A Perte. Sémantique d'alerte + un seul moment de marque.
--text#E8F1EE Texte. Blanc cassé, pointe de cyan.
spectral#19D3F0 · #7B2FF7 · #FF1E88 Symbole uniquement. Le spectre du signal, plein débit.
Signal verrouillé — latence, cadence, débit nominal Image perdue — perte de paquets, décrochage

Suite

Ce qui est provisoire, ce qui suit.

Concept — non figé

Le symbole ci-dessus est dessiné à la main en SVG : la direction est là, la finition vectorielle (optique des angles, ajustement des barres, jeu d'icônes UI assorti) demande une passe dédiée — un designer, ou un outil vecteur type Recraft / Illustrator + Firefly, avec cette page comme brief.

Si la direction te va

Je décline le symbole dans tous les emplacements d'assets du repo (9 PNG webOS/Linux/Steam Link + splash), régénère app_icon.h, rebuild desktop + webOS, commit + push. Icône provisoire mais cohérente, build débloqué.

Avant soumission store

Passe finition de l'art (interne ou Recraft/Firefly, indemnisé commercialement), webosbrew-ipk-verify, test sur la TV. Le système couleur / typo / overlay, lui, est prêt à être appliqué à l'UI.
